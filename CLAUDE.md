# AI Assistant Project Rules

## Project stack

- Node.js 22 LTS
- JavaScript
- npm
- Git/GitHub
- Cursor or VS Code for editing

## Conventions

- Prefer small, focused changes that are easy to review.
- Use clear JavaScript and avoid adding dependencies without documenting why.
- Keep secrets in environment variables; never commit `.env` files.
- Update `README.md` when setup, usage, or project scope changes.
- Use Conventional Commits: `type(scope): description`.
- Before handing off work, run the relevant tests or checks and report their results.

## AI workflow

1. Inspect the existing files before changing them.
2. Explain assumptions when requirements are ambiguous.
3. Make the smallest complete implementation.
4. Verify the result and summarize changed files and checks.
